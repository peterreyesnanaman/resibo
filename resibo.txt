| The Book by Amaranth Borsuk                 |
|   -The Book contains a broad discussion of  |
|    the book as a material and an idea. But  |
|    I think its Preface and Acknowledgments  |
|    section in particular speaks to the      |
|    inclusivity of formats and reading       |
|    approaches that Lit Club tries to        |
|    foster. I quoted the section in the      |
|    script for the first episode of Yes, We  |
|    Can Read. -Peter, 2026/09/01             |

|                                             |
| The End of Reading is Here by Rose          |
| Horowitch                                   |
|   -A sweeping look of reading– from the     |
|    Library of Alexandria to today’s         |
|    postliterate landscape. Really           |
|    interesting overview of what reading     |
|    feels like right now. We have so much    |
|    literature to read and they’re more      |
|    accessible than ever, but we as humans   |
|    have changed how we read. Even if we     |
|    don’t read books, we read A LOT. We read |
|    emails, ads, tweets, FB posts… Now we    |
|    rarely dedicate the time to read         |
|    literature because the world is          |
|    competing for our time. -They,           |
|    2026/09/17                               |
|                                             |
| The Elite College Students Who Can’t Read   |
| Books by Rose Horowitch                     |
|   -Professors at elite colleges observe how |
|    their students seemingly can’t read      |
|    anymore. The article pinpoints issues in |
|    previous levels of education—in high     |
|    school, reading lists are replaced by    |
|    reading excerpts; in elementary grades,  |
|    standardized tests push forth shorter    |
|    passages to get the main idea quicker.   |
|    Humanities and social sciences courses   |
|    are low in priority for students (who    |
|    lean towards practical careers), and so  |
|    the reading coursework, of course, will  |
|    be sacrificed in favor of other academic |
|    loads. Written in the USA context but    |
|    eerily familiar for us, too. -They,      |
|    2026/09/17                               |

| How to read critically in the age of bad    |
| media literacy by The Book Leo              |
